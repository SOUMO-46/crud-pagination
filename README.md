# Professional PHP OOP CRUD

A clean PHP + MySQL OOP CRUD project with server-side pagination, search, responsive CSS, and JavaScript validation/delete confirmation.

## Setup
1. Copy the folder into XAMPP/WAMP `htdocs`.
2. Start Apache and MySQL.
3. Open phpMyAdmin and import `database.sql`.
4. If your MySQL credentials differ, edit `config.php`.
5. Visit `http://localhost/php_oop_crud_professional/`.

## Included
- OOP MySQLi database layer
- Prepared statements for CRUD/search queries
- Server-side pagination
- Name/city search
- Add / Edit / Delete
- Responsive professional UI
- Client-side form validation
- Delete confirmation
- UTF-8 / utf8mb4 support
- InnoDB foreign key relationship
